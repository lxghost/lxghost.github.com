执行摘要 Executive Summary

CrowdStrike Intelligence 于 2026-10-07 前后披露：一桩针对韩国金融机构的定向攻击活动在 2026 年 9 月底至 10 月初活跃，并报告导致数据被外泄（exfiltrated data）。CrowdStrike 通过被动分析攻击者自身暴露的开放目录取证——其中泄露了 Claude Code 会话历史、ARTEX 配置文件、Claude memory 文件，以及一处 hxxp[:]//38.244.50[.]120:18899/.claude/CLAUDE.md 内含中文渗透测试 prompt 的项目指令文件。这些一手工件直接刻画了攻击者的工具链与作战手法。

核心手法：攻击者以 ARTEX（一款近期发布、中国开发的开源智能体(agentic)渗透测试框架）为主作战工具，通过 Claude Code 编排、以 DeepSeek v4.1-flash 为主 LLM 后端，辅以 GLM-5.3（智谱）、Grok 4.6；疑似经由 xcai[.]pro（疑似 LLM API 代理/经销商）采购模型；采用「主基础设施(香港 IP) + 38.244.50[.]120 上 ARTEX 实例」双服务器架构，并动用 9 个代理 IP 隐匿来源。会话还显示攻击者询问在哪里出售韩国数据泄露、寻找韩国 Telegram 数据售卖群，并请求生成一份罗列 ARTEX 行动成果的「安全研究员简历」（含自报个人信息）。

CrowdStrike 未将该活动归因到任何命名对手，仅以中等置信(moderate)评估攻击者「很可能为中文使用者、以经济利益驱动」。

⚠ 核心分析警示（证据分层纪律）：本议题的一手证据几乎全部在攻击者侧（开放目录里的文件、IP 清单、会话内容）——这些是「某文件/该内容存在」的事实。但「打了谁、拿到什么、卖没卖」这些受害侧结果，均为二手行业报道或攻击者自述：两家银行的入侵入口、'ARTEX' 字符串来源、数据外泄结论皆系转述，受影响组织数unconfirmed；疑似攻击者 PII（YY/电话/@YY520CN/年龄 vs 生日矛盾/华南理工/广东茂名）出现在「生成简历」这一可虚构语境，文档自身亦声明「无法确定性关联」。本所仅依赖单一来源(CrowdStrike)+二级媒体，无独立第三方验证——下文所有 High 均指「对文档保真度高」，而非「多源确证」。

竞争性假设 Alternative Hypotheses

H1（第1·中） 单人/小型中文背景黑客或渗透爱好者，经济驱动，用 ARTEX+LLM 快速实施入侵并图谋卖数据。支撑：中文 prompt、销赃询问、简历包装、平价 LLM 代理采购、短时多入侵。反证：自报 PII 含矛盾、语言/工具不排他。
H2（第2·中低） 服务化数据窃取-出售业务(cybercrime-for-hire)，ARTEX+LLM 仅提效，背后分工。支撑：多组织重叠IP、入口各异、双服务器工程化。反证：文档仅评个体、无团伙层级/品牌/站点证据。
H3（第3·中低） 简历身份画像属虚构/烟幕/false flag，真实身份不可知。支撑：年龄↔生日硬矛盾、简历=对外包装语境、文档措辞谨慎。注：对"PII 真实性"此假设置信反高于对 PII 的信任。
H4（第4·低） 国家级/承包代理借经济犯罪外观作案（韩国金融=地缘敏感）。反证：询问卖数据、用平价代理、简历自夸，更符合牟利个体而非情报纪律；无驻留/外传差异证据。不据本文档支持此归因升级。
H5（第5·低） 观测面混入多操作者，画像实为拼合体（IP 段分散、@YY520CN 亦见于另一不明攻击者）。反证：会话方法论/目标/架构高度一致、开放目录呈同一工作流。

趋势研判与关联（分析师语境，非本文档证据）

本案是 2026 年 agentic-AI 武器化主线的又一节点，与既有情报同源可串：GTIG《From Prompt to Autonomy》(2026-09)记录行为体用 AI 编码智能体＋预置 Markdown playbook 在 <6h 搭建全自动凭证收割、于 .claude 隐藏落盘并对 AI 助手做 prompt 注入；荷兰 DIVD 被 AI agent 借零日链秒级到 root、OpenAI 智能体入侵 Hugging Face、Plugin4Shell（Claude Code/Codex 等四代理零点击 RCE）等同属"工具链本身成攻击面"。ARTEX 的特殊信号在于：攻击者把开源智能体渗透框架与前沿 LLM 组合，把'单兵'的作战节奏抬到接近团伙级，而其因开放目录自曝 .claude/CLAUDE.md 反成取证富矿——攻击者的 OPSEC 失误面与防守方的暴露面是同一类风险的两面。此段系跨报告趋势类比，非由本文档直接支撑，作研判语境使用。
